# LifeFlow

A modern healthcare web app for blood donation discovery, donor management, appointment booking, and emergency blood requests.

## Features
- Donor login and registration
- Blood bank search and map view
- Eligibility tracking with 3-month rule
- Appointment booking and QR codes
- Admin dashboard for appointments, stock, requests
- Emergency blood request submission
- Demo mode using localStorage when backend services are unavailable

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Scripts
- `npm run dev` – run the app in development mode
- `npm run build` – build the production bundle
- `npm run preview` – preview the production build

## Notes
This project uses a demo dataset to simulate the complete application without external backend credentials.
